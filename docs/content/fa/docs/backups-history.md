> **اگر تغییری از `nginx -t` رد شود، اما باز هم اشتباه باشد چه؟**
> آن تست فقط ثابت می‌کند Nginx *بالا می‌آید*، نه اینکه تغییر شما درست بوده. برای این حالت باید بتوانید به عقب برگردید، و
> گونیکس برای همین دو لایه‌ی محافظ دارد.

## لایه‌ی اول: پشتیبان، قبل از هر نوشتن

پیش از اینکه گونیکس فایل یک هاست را بنویسد، یک نسخه‌ی تاریخ‌دار از آن در `/etc/gonix/backups/` ذخیره می‌کند. بعد می‌نویسد و `nginx -t`
را اجرا می‌کند:

- **اگر تست موفق باشد**، Nginx reload می‌شود و موفقیت در audit log ثبت می‌شود.
- **اگر تست شکست بخورد**، همان نسخه‌ی پشتیبانی که لحظاتی پیش گرفته شد جایگزین می‌شود. Nginx **هرگز** با پیکربندی خراب reload
  نمی‌شود و شکست (همراه با خطای Nginx) در audit log می‌ماند.

نسخه‌های پشتیبان قدیمی‌تر از `backup.keep_count` (پیش‌فرض ۲۰ نسخه برای هر فایل) خودکار پاک می‌شوند. صفحه‌ی **Backup / Restore**
هر هاست، نسخه‌های باقی‌مانده را فهرست می‌کند و هرکدام را برمی‌گرداند؛ آن هم با همان مسیر «اول تست، بعد reload».

## لایه‌ی دوم: تاریخچه، یک مخزن Git از همه‌چیز

وقتی `history.enabled` روشن باشد (پیش‌فرض روشن است) و `git` نصب باشد، هر تغییر موفق در `/etc/gonix/history.git` کامیت می‌شود و
`/etc/nginx` درخت کاری آن است. هیچ‌چیز **داخل** `/etc/nginx` اضافه نمی‌شود.

```bash
sudo gonix history list --lines 10
sudo gonix history show 3f9c2ab           # تفاوت (diff) همان تغییر
sudo gonix history restore 3f9c2ab --yes  # اول با nginx -t آزمایش می‌شود، مثل هر کار دیگری
```

در TUI هم همین امکان زیر **Configuration History** هست.

{{< callout type="info" >}}
**چرا پوشه‌ی Git بیرون از `/etc/nginx` است؟** تا آنجا تمیز بماند: بدون یک پوشه‌ی `.git` که ابزارهای پشتیبان‌گیری یا نرم‌افزارهای
دیگر را گیج کند، و بدون چیزی که ناخواسته در یک `include` بیفتد.
{{< /callout >}}

## کدام را به کار ببرم؟

| وضعیت | چه کار کنید |
|---|---|
| «همین الان این هاست را ذخیره کردم و اشتباه شد» | **Backup / Restore** همان هاست (سریع و برای یک فایل) |
| «هفته‌ی پیش یک چیزی عوض شد؛ چه چیزی؟» | `history list` و `history show` |
| «همه‌چیز را به سه‌شنبه برگردان» | `history restore` |
| «همه‌چیز را به یک سرور دیگر ببر» | [export و import]({{< relref "migration" >}}) |
